# A Zwift workout's prescription is on whatsonzwift.com — optional, Garmin stays the truth

Garmin stores only the summary of a ride (duration, NP, load, TE). **https://whatsonzwift.com**
documents the PRESCRIBED structure of any Zwift workout: warm-up, every interval with % FTP and
duration, cool-down, stated purpose.

**Optional, not a step.** Execution always comes from Garmin. Reach for it only when the prescription
changes the read — e.g. whether a ride was VO2max or endurance decides the same-day lifting call. A
26-minute VO2max session (8.5 min at 123–130% FTP) is cardiovascularly hard but muscularly cheap, so
legs the same evening are fine; a 1 h 53 climb is a leg session in itself. Garmin's `load` rated
those two 70 vs 66 — it cannot tell them apart.

**How.** The activity name carries the path, e.g. `Zwift - Le Col - Training With Legends - Dame
Sarah Storey - 8.5 Minutes Of Pain` → `whatsonzwift.com/workouts/le-col-training-with-legends/
dame-sarah-storey-85-minutes-of-pain`. Guessing the slug often 404s: search the domain first, then
fetch. Retired Zwift workouts are usually still documented there.

**Planning is a different rule.** Every Zwift ride the coach plans names its workout from this site
(`zwift-workout-named.md`, 2026-11-05). This file is about reading back a ride that was already done.
